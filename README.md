# Personal Portfolio Website

This is my personal portfolio website, built using Fable 5 to showcase my projects, skills, and experience as a Computer Engineer.

## 🚀 Overview

The portfolio is designed with a strong focus on minimalism, performance, and user experience. It serves as a central place to explore my work across multiple domains including software development, embedded systems, and AI-driven solutions.

## ✨ Features

* Modern and responsive UI
* Smooth animations and transitions
* Project showcase with tech stacks
* Clean and structured layout
* Optimized performance

## 🛠 Tech Stack

* Fable 5
* HTML/CSS
* JavaScript
